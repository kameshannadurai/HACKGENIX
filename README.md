## 🛠️ Remote Git Setup
To connect or clone this repository:
```bash
git remote add origin https://github.com/kameshannadurai/HACKGENIX.git
git branch -M main
git push -u origin main
```
Or to clone directly:
```bash
git clone https://github.com/kameshannadurai/HACKGENIX.git
```
